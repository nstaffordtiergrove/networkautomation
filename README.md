# Network Automation
Switch/Router automation modules using NetMiko library


This repository is a set of modules for TierGrove, Inc. It will remain publicly available, but I will be the only one making commits to the repository. This code is for TierGrove, Inc operations/testing but can very easily be used in any organization that deploys networking equipment to conduct business and/or academia. IP's for the internal TierGrove network have been removed for security but code comments will point to where someone would insert public/private IP/subnets.

All modules created and distributed here have been built and tested successfully at TierGrove, Inc. Codebases here and the NetMiko library are stable builds that are publicly available.

Python chosen because that is what NetMiko is in written and I WILL NOT be converting this to C++ at this time.

NOTE: ALL CODE IN THIS REPOSITORY IS NON-AI GENERATED. ALL AI GENERATED CODE IS AUTOMATICALLY BANNED FROM USE IN THIS REPOSITORY.

REQUIREMENTS:

- Python 3.14.10 (3.15.2 has missing files)
- IDE (Geany is used here)
- SSH Configured
- NetMiko installed (github.com/kbyers/netmiko)
